# Maintaining Context Ledger

The runtime is Python 3.10+ and standard-library only. Keep goal integrity, explicit session binding, bounded retrieval and local-only operation intact.

Host manifests and Claude commands are generated by `python3 scripts/package.py`. Edit that generator before regenerating. The shared source is `skills/context-ledger/scripts/ledger.py`; avoid host-specific copies of the runtime.

Run `python3 -m unittest discover -s tests -v` and `python3 scripts/validate.py` after runtime or packaging changes. Use a temporary project for hook tests. Do not use a real user's state or transcripts as fixtures. Native smoke checks should not mutate global user configuration.

Document host protocol changes against official sources. Never describe a metadata hash, evidence record or synthetic fixture as proof of coding-agent accuracy. Keep runtime memory out of commits. Publishing or installing globally requires a user request for that action.
